# Настройка чтения с реплик и консистентность

Описание операций коллекций, по использованию primary/secondary реплик, с описанием допустимых задержек операций на secondary

### Коллекция products

| операция                                                   | реплика   | Допустимая задержка | Обоснование выбора.                                |
|------------------------------------------------------------|-----------|---------------------|----------------------------------------------------|
| Частые обновления остатков при покупках.                   | Primary   |                     | необходимо показывать актуальное количество товара |
| Поиск товаров по категориям и фильтрация по диапазону цен. | Secondary | 1-5 секунд          | не частое обновление                               |
| Описание товара на странице продукта.                      | Secondary | 1-5 секунд          | не частое обновление                               |


### Коллекция orders

| операция                                                     | реплика   | Допустимая задержка | Обоснование выбора.                  |
|--------------------------------------------------------------|-----------|---------------------|--------------------------------------|
| Быстрое создание заказов с одновременным списанием остатков. | Primary   |                     | Обновление данных в реальном времени |
| Поиск истории заказов конкретного пользователя.              | Secondary | 1-5 секунд          | не частое обновление                 |
| Отображение статуса заказа.                                  | Primary   |                     | Получение данных в реальном времени  |
