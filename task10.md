# Миграция на Cassandra: модель данных, стратегии репликации и шардирования

## 10.1 Какие части данных интернет-магазина являются критически важными с точки зрения целостности и скорости обработки.

- товары - Частые обновления остатков при покупках.
- заказы - Быстрое создание заказов с одновременным списанием остатков.
- история заказов - Отображение статуса заказа.
- корзины - информация обновляяется в реальном времени

Для этих данных применение Cassandra имеет смысл, так как она как раз относится к AP по CAP-теореме (доступность и устойчивость к разделению).

## 10.2 Концептуальная модель для выбранных критически важных сущностей.

1. Заказы (orders) 
[orders.plantuml](orders.plantuml)
   - Partition key: id - уникальный id, равномерное распределение без горячих партиций
   - Кластерный ключ: date, user_id - порядок по дате оформления заказа

2. Товары (products)
[products.plantuml](products.plantuml)
   - Partition key: id, category - уникальный id, равномерное распределение без горячих партиций
   - Кластерный ключ - Не требуется специальный. Внутри партиции (все товары одной категории) данные хранятся в порядке их записи..

3. Корзины (carts)
[carts.plantuml](carts.plantuml)
   - Partition key: user_id, session_id - уникальные идентификаторы, равномерное распределение без горячих партиций
   - Кластерный ключ: updated_at - обеспечивает порядок по времени обновления

## 10.3 Стратегии обеспечения целостности

| Стратегия           | Сущности                  | Обоснование                                                                                             |
|---------------------|---------------------------|---------------------------------------------------------------------------------------------------------|
| Hinted Handoff      | продукты, истории заказов | Учитываем, что данные могут расходится в какой-то момент времени                                        |
| Read Repair         | корзина                   | Корзина должна быть максимальна актуальной, поэтому восстанавливаем (если необходимо) при чтении данные |
| Anti-Entropy Repair | продукты, заказы          | Периодически необходимо делать синхронизацию, но так как объем большой делаем в фоновое время           |
